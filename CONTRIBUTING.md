# Contributing

TwoPointWeather is maintained by TwoPoint Development.

## Reporting problems

Use the repository bug report form and include:

- FiveM server artifact version
- OneSync configuration
- TwoPointWeather version
- `/weather audit` output
- Affected client's `tpweatherdiag` output
- Relevant server console and F8 console messages
- A list of any other weather or time resources

Remove private identifiers, tokens, license keys, and confidential server information before posting logs.

## Pull requests

1. Create a focused branch.
2. Keep changes limited to one issue or feature.
3. Preserve the `TwoPointWeather` resource name and `TwoPointWeather.admin` ACE object.
4. Do not add another time or weather authority.
5. Run Lua syntax checks before submitting.
6. Describe how the change was tested with multiple clients.
7. Keep TwoPoint Development attribution intact.

By contributing, you agree that your contribution may be distributed under the repository license.
